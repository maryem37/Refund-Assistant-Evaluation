# Refund-Assistant-Evaluation
Un agent conversationnel qui traite les demandes de remboursement en vérifiant l’identité de l’utilisateur, ses achats et les délais d’éligibilité, puis en créant un ticket uniquement pour les articles admissibles. Le projet inclut des évaluations automatisées pour mesurer la précision des outils, le respect du plan et la réussite des tâches.
